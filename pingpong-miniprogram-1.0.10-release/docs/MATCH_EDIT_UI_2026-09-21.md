# 球局编辑页体验调整

状态：本地完成，已随“0921编辑分享优化”上传客户端 1.0.10；公众平台设为体验版仍需确认。本页 UI 调整没有修改云函数或数据库，后续生产 api 部署另见部署记录。

- 用白底分区替代多层边框卡片，标题改为全宽输入，日期独立一行，开始/结束时间对称排列。
- 人数数字居中，拖动滑块实时更新；练球方式、订台状态、加入方式使用同规格居中按钮。页面样式提高选择器优先级，避免全局 button 规则覆盖字号、宽度与留白。
- 默认显示当前球馆及地址，点击“更换”展开搜索，放大镜和输入框共用分隔。选择完成自动收起；搜索结果不再影响当前已选球馆展示。
- 增加 1 / 1.5 / 2 小时快捷时长，跨天明确提示，修改安排仍执行原有球台状态重置与成员重新确认规则。
- 费用与备注按需展开，有既存费用或备注时默认展开；保留标题、行政区、球龄、费用、备注等已有字段。
- 保存栏固定显示修改状态。提交中及成功返回前锁定输入，避免重复提交和保存后继续输入被丢弃。校验失败定位相关分区。

验证：完整 `npm test` 通过；`npm run check:release` 通过；本次文件 `git diff --check` 通过。新增测试覆盖球馆选择状态、快捷时长、滑块预览、保存期间与保存完成后的事件锁定。

视觉检查使用真实 WXML/WXSS 的本地浏览器预览和模拟数据，检查了 390px 首屏、320px 窄屏、长球馆名称/地址、搜索展开、人数选项和固定保存栏；不是微信真机截图，也没有向生产环境创建或修改球局。
