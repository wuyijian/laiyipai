# 搭拍子发布检查清单

此清单分为代码内门禁和必须由小程序管理员完成的外部配置。任何一项未完成都不应提交正式审核。

## 代码与数据边界

- [x] 页面只通过 `utils/api.js` 调用云函数，不直接读写云数据库。
- [x] 业务数据不写入本地存储；本地只保存筛选、草稿和协议版本。
- [x] 生产工程不附带虚构球馆、教练、球局、评分、距离或视频。
- [x] 写操作使用 OPENID 服务端鉴权和 `requestId` 幂等。
- [x] 抢位、审批、取消和教练库存使用事务及版本控制。
- [x] 私有页面不进入 sitemap。
- [x] 朋友圈只开放首页及公开详情，分享参数仅包含公开资源 ID。
- [x] 工程不声明或加载未使用的第三方插件。
- [ ] `npm run check:release` 零错误通过。

## 微信平台与环境

- [ ] `project.config.json` 已填写认证主体下的正式 AppID。
- [ ] 已建立相互隔离的测试、生产云开发环境，客户端指向正确环境。
- [ ] 主体、服务类目、小程序名称与实际业务一致。
- [ ] 微信隐私保护指引逐项声明实际处理的信息，版本号与客户端一致。
- [ ] 已配置客服入口、举报处理负责人和可公开的服务联系方式。

## 数据库、函数与存储

- [ ] 全部集合已创建，客户端读写权限均为拒绝。
- [ ] `venue_submissions` 四个索引均可用；旧版直接公开的 `source:community` 球馆已逐条复核，无法确认的记录已下架。
- [ ] `player_friends` 已创建且拒绝客户端直连，`user_updated`、`friend_updated` 两个索引均显示“可用”。
- [ ] 新版存储规则已应用，仅保留客户端本人头像路径写入，不删除历史媒体及索引。
- [ ] 组合索引、地理索引，以及 `upload_tickets.expires_asc`、`rate_limits.expires_asc` 两个 `expiresAt` 普通升序索引均显示“可用”；未配置 TTL 索引。
- [ ] `api`、`mediaCallback`、`accountCleanup` 已部署到生产环境。
- [ ] 隐私政策版本、管理员 OPENID、教练取消时限已配置。
- [ ] 管理员重新进入小程序后，“我的 → 运营管理”仅对授权账号显示“教练认证审核”和“历史球馆审核”；普通账号直达两个审核页均返回无权限。
- [ ] 提交审核时，小程序消息推送 `(event,wxa_media_check)` 唯一绑定到测试环境的 `mediaCallback`，体验/审核版本的正常头像完成 `reviewing → passed`、风险头像完成 `reviewing → rejected`，历史超时头像可重新提交；客户端不能直接调用回调函数。审核通过后、点击正式“发布”前，再把同一订阅切到生产环境并完成生产回调核验。详见 `docs/AVATAR_MODERATION.md`。
- [ ] `accountCleanup` 定时触发器已启用，注销任务及过期上传凭证/限流桶清理已实测，客户端不能直接调用。
- [ ] 云函数错误率、延迟、审核积压、存储用量和清理失败告警已启用。
- [ ] 已完成生产数据库备份与恢复演练。

## 真实供给

- [ ] 每家杭州球馆已复核正式名称、地址、经纬度、电话、营业状态和官方预约方式。
- [ ] 场馆图片已取得授权，来源与复核时间可追溯。
- [ ] 每位教练已核验身份、资质、价格、可用时段和履约联系方式。
- [ ] 下架、停业、临时时段变更有明确运营负责人和更新时限。
- [ ] 球局费用、教练费用均明确“预估、到店支付、平台不代收”。

## 隐私与内容安全

- [ ] 文字内容安全覆盖昵称、技术标签、球局、聊天、取消原因和举报。
- [ ] 内容安全服务异常时拒绝写入或保持不可见，不降级公开。
- [ ] 安全与违规头像测试各一张，均正确进入通过或拒绝状态。
- [ ] 个人视频无上传、列表、预览或删除内容卡片；球友资料和球局详情不请求/返回个人视频，通用文件解析不再解析 `user_videos`，存储规则拒绝 `user-videos/` 读写；旧版上传仍被拒绝，兼容列表不含展示元数据，删除与注销清理可用。
- [ ] 举报、屏蔽、申诉、内容下架与审计记录流程已人工演练。
- [ ] 注销后账号立即停用，未来预约释放，个人媒体和可删除资料按期清理。
- [ ] 未成年人提示、公共球馆限制、头像与历史媒体处理文案已复核。

## 功能回归

- [ ] 两个真实账号同时抢最后一个名额，只能一个成功且人数不超限。
- [ ] 申请制球局完成申请、拒绝、批准、取消、改期和逐人确认。
- [ ] 双账号实测直接加入和申请获批后互为球友；候补/待审/拒绝不建立关系，同一球局重试不重复计数，球友局筛选与拉黑隐藏均正确。
- [ ] 非成员不能读写聊天；被屏蔽双方不能继续互动或互相推荐。
- [ ] 同一请求重放创建、加入、发消息和教练预约，不产生重复记录。
- [ ] 新球馆提交后立即可搜索并用于发布；两个账号并发提交同名球馆只生成一个公开球馆，文本安全拒绝时不产生任何记录。
- [ ] 新球馆录入幂等、同名冲突、注销并发已用普通账号演练；历史审核越权、版本冲突和待审撤回仍已用运营账号回归。
- [ ] 教练认证已完成通过、驳回、分页、版本冲突、权限撤销和申请人注销并发回归；通过后教练档案保持下架，名称型球馆可作为授课地点且不会获得场馆认证标识。
- [ ] 管理员可分页查看并分别删除球馆和教练；普通用户被拒绝；弱网重试复用请求号；删除后公开列表和新建业务不可使用该记录，历史球局、聊天与预约仍可查看。
- [ ] 管理员审核写入超时后先用对应单条状态接口核对；不得以待审首页中缺少记录推断审核成功，也不得自动重放审核写操作。
- [ ] 新设备可打开分享球局；过期、取消或下架页面有明确状态。
- [ ] Android 微信真机可从公开页右上角分享到朋友圈，分享卡片可正确回到原资源。
- [ ] 弱网、断网、重复点击、午夜日期切换和服务端版本冲突均可恢复。
- [ ] iPhone 与主流 Android 真机完成头像上传、历史媒体查看/删除、两个上传入口移除、键盘和安全区回归。
- [ ] 体验版使用受控真实测试账号验收，不向审核人员展示未经核验的供给。
