# 运营与故障处置手册

## 每日检查

- 查看云函数错误率、P95 延迟、数据库/存储用量和限流异常。
- 对 `AUDIT_WRITE_FAILED` 设置告警；新球馆即时录入以 `venue_submissions` 的请求号、版本、关联球馆和发布时间为主记录，历史审核仍以审核人、时间和理由为准。
- 从“小程序 → 我的 → 运营管理 → 教练认证审核”查看教练待审队列；同时查看头像、历史比赛视频、球馆场地照片与举报队列。`admin.venueSubmissions.pending/review` 只处理旧版本遗留的待审新球馆。历史比赛视频仅作处置和清理，不得重新公开；场地照片操作见 `docs/VENUE_PHOTOS.md`。
- 从“小程序 → 我的 → 球馆与教练管理”删除重复、错误或停止运营的球馆和教练。确认框会说明影响；删除后检查公开列表已下架即可。该操作保留历史球局与预约，禁止在数据库控制台物理删除或手工清理关联记录。
- 抽查未来 72 小时球局中的停业球馆、异常费用、私人地址和诱导转账文案。
- 复核教练时段重复、取消积压和到期未释放库存。

## 内容审核

1. 文字安全检查不可用时，API 返回错误，不把内容落库或公开。
2. 头像真实状态按 `reviewing → passed/rejected/failed` 收敛；仅 `passed` 可进入用户公开资料。`failed` 和超过 35 分钟的 `reviewing` 可由本人重新发起，重试时不得把晚到的旧回调覆盖到新任务。完整处置见 `docs/AVATAR_MODERATION.md`。
3. 比赛视频和场馆照片上传已停用；历史视频待审记录仍保持 `reviewing`，但任何审核结果都不得进入用户资料、球局详情或通用文件解析。运营按留存制度执行拒绝、删除或迁移，不因停用上传自动删除旧内容。
4. 举报优先级：人身安全、未成年人和违法线索最高，骚扰与诱导转账其次，一般不实信息再次。
5. 处置应记录操作人、时间、理由和对象版本；需要保全证据时仅运营安全人员可见。

头像审核积压时，先在消息推送配置中确认 `(event,wxa_media_check)` 指向保存该记录的同一环境和 `mediaCallback`，再查函数日志。测试与生产共用 AppID 时同一事件只能绑定一个环境；上线前必须绑定生产环境。修好订阅后，让历史超时用户在“我的”页点击“重新提交”，不能直接把积压记录手工改为 `passed`。

## 场馆与教练变更

- 新球馆录入由服务端标准化名称并查重后即时公开；运营日常通过举报和目录巡检处理明显虚假、重复或不规范名称。旧待审记录通过时填 `decision:approve` 和当前 `expectedVersion`；无法核实时填 `decision:reject` 与 2—200 字可执行理由。若接口返回 `VENUE_NAME_CONFLICT`，先在目录合并或处理同名待审/停用记录，不得强行重新上架。
- 申请人注销后，待审单会转为终态 `withdrawn`；不得手工改回 `reviewing` 或继续审核。
- 新增球馆前通过场馆电话、官方账号或现场渠道复核，不以聚合平台页面作为唯一依据。
- 教练认证通过前核对申请人身份、手机号、资历说明和常驻球馆；只能关联已上架的球馆目录记录。名称型球馆可作为授课地点，但不得描述为已核验场馆或合作场馆。管理员只需选择核验日期，内部审核标识由服务端按请求自动生成；拒绝时填写可执行的修改原因。审核通过生成的教练档案默认 `active:false`，只有补齐真实价格与可约时段后才能上架。
- 审核写入超时或结果未知时，先用 `admin.coachApplications.get` 精确核对单条状态；仍为待审时才允许由管理员主动以同一请求号和完全相同的审核参数重试。不得用“待审列表里找不到”推断审核成功，也不得自动重放写操作。
- 停业、地址变更或失联的供给先下架，再调查；不要保留可继续预约的旧时段。
- 教练资质、价格或联系方式变化后更新复核时间；未经重新确认的未来时段暂停展示。
- 图片授权记录、数据来源链接、复核人和复核时间保存在运营台账，不放进客户端包。

## 故障分级

- P0：身份越权、私有聊天泄露、库存超卖、敏感数据公开。立即关闭相关入口或回滚，保全日志并通知负责人。
- P1：无法发布、加入或取消，审核队列停止，云函数持续高错误率。暂停受影响功能，给出明确错误状态并优先修复。
- P2：单页样式、非关键媒体或个别供给信息问题。下架错误内容并在正常版本节奏修复。

## 回滚

1. 发布前记录客户端版本、云函数版本、环境变量摘要和数据库备份点。
2. 客户端问题回滚到最近审核通过版本；API 契约在同一主版本内保持向后兼容。
3. 云函数回滚后验证登录、列表、加入、取消和消息权限，再恢复入口。
4. 数据迁移必须可重复执行并留审计记录；不得用删除生产集合的方式回滚。

## 注销与隐私请求

- 注销成功后账号立即不可继续操作，异步任务取消未来预约、释放名额并删除可删除媒体。
- 清理任务连续失败触发告警；人工处理不得把用户内容复制到个人设备。
- 对依法需要留存的数据做访问隔离和到期删除，不继续用于推荐或产品分析。
