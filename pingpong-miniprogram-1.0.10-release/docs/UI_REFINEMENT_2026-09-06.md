# 来一拍 UI 与交互整理 · 2026-09-06

本轮修改的是现有原生微信小程序，共 11 个注册页面，不是设计图片或网页演示。未修改云数据库、未提交预约、未发送消息、未上传或部署云函数。

## 统一设计

- 白色背景、深绿色主操作、轻灰分区；减少大色块、层层套卡与装饰性文案。
- 统一标题、正文、辅助文字、页面边距、细边框、弹层及底部安全区。
- 修正微信 style v2 默认按钮宽度、外边距与文字样式造成的挤压和居中问题。
- 为四个原生底部导航添加本地线性图标；可用 `node scripts/generate-tab-icons.js` 重建。

## 页面与交互

| 页面 | 本轮调整 |
| --- | --- |
| 首页 | 简化头部和筛选；紧凑日期栏；重排球局与球馆卡片；保留真实空状态 |
| 发起 | 简化为清晰表单分区；保留 1–8 人紧凑单行滑块；发布错误紧邻底部提交按钮 |
| 预约 | 日期与时段分开展示；“当前安排 / 历史记录”；进行中的球局隐藏取消；突出沟通入口 |
| 我的 | 收拢运动档案；轻量视频与常去球馆模块；教练认证入口；找球馆直达首页球馆区 |
| 球馆详情 | 无照片时不显示伪封面；名称型球馆不伪造地址；底部固定发起按钮 |
| 球局详情 | 强化时间、地点、成员和费用层级；统一加入、结果与提示面板 |
| 球局沟通 | 调整消息字号、气泡、快捷短句、输入栏和安排弹层；快捷短句仍需确认发送 |
| 球友资料 | 统一头像、资料行、技术标签和审核视频列表 |
| 教练详情 | 简化教练信息与日期时段；价格随选择更新；切换时段清理旧请求编号；刷新失败保留已展示内容 |
| 教练认证 | 统一输入框、选项、分组说明和显式同意操作 |
| 设置 | 清晰列表分区；保留隐私、协议、屏蔽、注销安全流程 |

## 仍需单独验收

- 微信真机上的软键盘、较小屏幕、系统放大字体与网络波动。
- 有真实可约教练时的完整预约流程，以及视频上传、审核、播放链路。本轮检查个人页时曾出现视频记录暂未同步提示，不能视为已修复云端同步。
- `utils/cloud-config.js` 的测试与生产环境隔离配置仍被发布检查拦截；本轮没有擅自填写生产环境。
