# 我的约球统计

状态：本地实现并验证；本轮没有部署生产 api、上传小程序或修改生产业务数据。

## 展示与统计口径

“我的”页头像信息下方增加三列：历史参与、本月参与、发起成局。三列数字与文字居中，不增加排名、胜率、积分或社交成就。

- 历史参与：球局有有效的开始、结束时间，已结束且未取消/删除，报名人数至少 2 人（包括发起人）；本人成员状态为 host/joined，已确认当前日程。同一球局计一次。
- 本月参与：上述历史参与中，开球时间在北京时间本月的记录。
- 发起成局：上述历史参与中，由本人发起的记录，而不是全部发布次数。
- 待审核、候补、拒绝、退出、未成局、未结束、未确认改期不计入。老记录没有确认版本时，只兼容未改期的第一版日程。
- 这不是签到系统，不证明实际到场或真实运动时长。“统计说明”提供完整口径。

## 架构与兼容

- 独立只读接口 `profile.stats.get`，身份取受信微信上下文，仅查看本人；游客及伪造目标用户不可查询其他账号统计。
- 使用已有 match_members、matches；不新建集合、不修改原记录、不加索引。
- 复用 match_members 的 user_updated 索引，每页 100 条本人记录，关联球局每批 20 条，只读取必要字段。突破预约列表最近 50 条限制；缺失关联记录不计入。
- 云端按请求计算，不把可能过期的累计计数写入用户资料；数据错误或读取失败不返回部分结果和假零。
- 不改动 profile.get/bootstrap 的接口响应。新接口尚未部署时客户端显示局部“统计服务待更新”。
- 基础资料先显示，统计独立加载；失败保留上次数字并提示重试，首次失败显示横杠而非 0。下拉刷新更新统计，页面离开或账号变化时丢弃迟到响应。
