# 附近球馆

首页右上角“附近球馆”进入独立页面。仅在用户点击“获取大致位置并查找”或“重新定位”时先请求隐私授权，再通过 `wx.getFuzzyLocation({ type: 'gcj02' })` 获取大致坐标。无需登录，不在首页启动时自动定位。

默认半径 10 公里，可选 3 / 5 / 10 / 20 / 50 公里。调用现有公开接口 `venues.nearby`，展示最近至多 50 家球馆，支持距离排序、详情、地图导航、空结果扩大范围和失败重试。结果来自自有 `venues` 集合，不是外部地图 POI 全量搜索；只有名称、没有坐标的球馆不会出现在附近结果中。球馆列表仍可手动浏览。

用户坐标仅保留在当前页面实例，用于切换半径和失败重试；退出页面释放，不写入缓存、用户资料或业务集合。距离与范围均基于模糊位置估算，以“约 1 公里”等粗粒度文案展示，不代表精确定位、导航路程或严格的覆盖边界。快速切换范围和退出页面时丢弃迟到的请求结果。

## 环境接入

- 沿用当前云函数 `venues.nearby`，本次无需变更云端路由。
- 确认云开发 `venues.location` 为 GCJ-02 坐标的 Geo.Point，并已建立 `database/indexes.json` 中的地理索引。公开查询仅返回 `active: true`、`verificationStatus: verified` 的球馆。
- 小程序管理后台需开通地理位置接口权限，在隐私保护指引中声明位置信息及“基于模糊位置查找附近球馆并展示估算距离”的用途。代码已补充 `scope.userFuzzyLocation` 用途和 `requiredPrivateInfos: [getFuzzyLocation]` 声明，后台权限与隐私文本不会随代码自动生效。
- 本分支不自动发布小程序，不修改生产数据。

## 验收

1. 游客打开首页、进入附近页，不应自动请求定位；主动点击后才出现隐私与位置授权。
2. 拒绝隐私授权或定位授权，不应查询附近接口；可重试、打开定位设置或浏览杭州球馆。设置返回后需主动再次点击查找。
3. 在开发者工具设置已知坐标，准备多个合法场馆位置，确认距离顺序、范围变化、详情跳转和导航坐标。
4. 网络断开、系统定位关闭、没有收录球馆时，显示对应反馈与恢复入口；查询失败不能把旧结果当作新范围结果。
5. 快速切换半径、重新定位或退出页面后，不出现旧请求回写。
6. 在真机开发版、体验版复测定位权限、微信地图导航与不同字号的页面布局。

自动化验证：`npm test`、`npm run test:cloud`、`npm run check:structure`。`tests/location.test.js` 覆盖隐私拒绝、定位拒绝、距离排序、范围请求竞争、重试、浏览回退和页面卸载。真机权限弹窗和地图导航需要微信环境验收。

旧版微信不支持 `getFuzzyLocation` 时展示升级提示，并保留手动浏览入口，不回退到精确定位。统一位置工具在调用前进行能力检查；定位被拒绝时只提示用户主动修改授权。

接口资料：[腾讯官方位置 API 说明](https://intl.cloud.tencent.com/zh/document/product/1219/57733)、[微信 API 文档入口](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.getFuzzyLocation.html)。
