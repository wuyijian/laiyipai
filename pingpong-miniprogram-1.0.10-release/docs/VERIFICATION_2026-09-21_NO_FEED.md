# 1.0.10 动态下线与头像排查

## 已实现

- 首页只提供找球局、约教练，不再提供动态。
- 我的 → 我的球友，只显示已同场的球友；取消可约动态、心得发布、公开回复。
- 旧动态详情链接仅展示下线提示，旧 `mode=updates` 首页链接回到找球局。
- 服务端对 API v1/v2 的六个历史动态/回复 action 统一返回 `FEATURE_REMOVED`；不依赖客户端版本或审核开关。
- 历史内容未删除，账号注销清理流程保留。
- 头像状态查询归为只读请求（8 秒预算、并发合并），不会每次轮询都清空其他在途读请求。
- 缺少或损坏时间字段的历史待审核头像返回可重试的超时状态，不会无限显示审核中；未审核图片不公开。
