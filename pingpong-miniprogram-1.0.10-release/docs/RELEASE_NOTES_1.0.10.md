# 来一拍 1.0.10 发布说明

## 微信版本描述

修复球局编辑与发布、球馆搜索和常去球馆标记；优化消息红点、私聊加载、首页与场馆首屏性能；停用头像上传和公开动态，提升审核兼容性与稳定性。

## 本版重点

- 球局支持编辑，发布约球信息使用结构化表单。
- 球馆首屏按页加载，支持服务端搜索，并优先复用短时缓存。
- 消息列表合并查询，修复失效会话指针导致的反复重试，客户端采用单飞退避刷新。
- “我的”保留未读消息红点和分球局消息入口。
- 用户头像统一为稳定系统头像，不再触发头像上传或媒体审核。
- 继续兼容 1.0.7 客户端；已停用的动态和媒体接口返回明确状态，不产生新 UGC 数据。
