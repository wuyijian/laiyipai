# 搭拍子 1.0.10 发布说明

## 微信版本描述

本版聚焦球局邀约工具：移除公开动态、心得发布和动态回复，保留找球局、发布与编辑球局、球馆搜索、常去球馆标记及球局内消息提醒，优化首页加载与头像审核状态。

## 本版重点

- 球局支持编辑；发布与编辑均保留标题、见面备注和原有约球字段。
- 球馆首屏按页加载，支持服务端搜索，并优先复用短时缓存。
- 消息列表合并查询，修复失效会话指针导致的反复重试，客户端采用单飞退避刷新。
- “我的”保留未读消息红点和分球局消息入口。
- 保留 1.0.7 的头像选择、上传、异步审核、状态轮询与失败重试。
- 移除首页动态、球友动态发布、心得分享和公开回复。球友页只显示同场球友；旧分享链接显示下线提示。
- 云端统一停用 `friendUpdates.*` 与 `updateComments.*` 已有路由，对 API v1/v2 都返回 `FEATURE_REMOVED`，不按审核状态开关。
- 历史动态数据不因功能下线而删除，保留账号注销清理；图片、视频和新增场馆照片上传继续关闭。
- 头像仍须平台安全审核，未通过的图片不得公开；回调配置和真实审核闭环须单独核验，不以本地模拟测试替代。
