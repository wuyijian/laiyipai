# 来一拍 1.0.10 发布说明

## 微信版本描述

基于已审核通过的 1.0.7 完整能力，修复球局编辑与发布，优化球馆搜索、常去球馆标记、消息红点、私聊加载和首屏性能。

## 本版重点

- 球局支持编辑；发布与编辑均保留标题、见面备注和原有约球字段。
- 球馆首屏按页加载，支持服务端搜索，并优先复用短时缓存。
- 消息列表合并查询，修复失效会话指针导致的反复重试，客户端采用单飞退避刷新。
- “我的”保留未读消息红点和分球局消息入口。
- 保留 1.0.7 的头像选择、上传、异步审核、状态轮询与失败重试。
- 保留 1.0.7 的球友动态、动态详情、公开回复和从动态发起约球；继续关闭图片、视频和新增场馆照片上传。
